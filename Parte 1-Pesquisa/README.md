Pesquisa – Fundamentos do Desenvolvimento Web
Frontend

Frontend é a parte visual de um site ou aplicação web, ou seja, tudo aquilo que o usuário vê e interage diretamente no navegador. O desenvolvimento frontend utiliza principalmente três tecnologias:

HTML → estrutura da página
CSS → estilização e aparência
JavaScript → interatividade e comportamento

O objetivo do frontend é criar interfaces intuitivas, responsivas e agradáveis para os usuários.

Cliente x Servidor

O modelo Cliente-Servidor é a base do funcionamento da internet.

Cliente

O cliente é o dispositivo ou navegador que faz uma solicitação de informação. Exemplo:

Google Chrome
Firefox
Aplicativos móveis
Servidor

O servidor é o computador responsável por armazenar, processar e enviar os dados solicitados pelo cliente.

Funcionamento
O cliente envia uma requisição.
O servidor processa o pedido.
O servidor responde com os dados.
O cliente exibe o conteúdo ao usuário.

Esse modelo permite que aplicações web funcionem de forma organizada e eficiente.

HTML

HTML (HyperText Markup Language) é a linguagem de marcação utilizada para criar a estrutura das páginas web.

Com HTML é possível adicionar:

Títulos
Parágrafos
Imagens
Links
Tabelas
Formulários

Exemplo simples:

<h1>Olá Mundo</h1>
<p>Minha primeira página web.</p>

O HTML organiza o conteúdo da página.

CSS

CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas HTML.

Com CSS podemos:

Alterar cores
Definir fontes
Ajustar tamanhos
Criar animações
Tornar páginas responsivas

Exemplo:

body {
    background-color: lightblue;
    font-family: Arial;
}

O CSS melhora a aparência e a experiência do usuário.

JavaScript

JavaScript é uma linguagem de programação usada para adicionar interatividade às páginas web.

Com JavaScript é possível:

Criar menus dinâmicos
Validar formulários
Atualizar conteúdos sem recarregar a página
Criar jogos e aplicações web

Exemplo:

alert("Bem-vindo ao site!");

Hoje, JavaScript é uma das linguagens mais importantes do desenvolvimento web.

W3C

W3C (World Wide Web Consortium) é uma organização internacional responsável por criar padrões para a web.

O W3C define regras e recomendações para tecnologias como:

HTML
CSS
Acessibilidade
Compatibilidade entre navegadores

Seu objetivo é garantir que a web funcione corretamente para todos os usuários e dispositivos.

Site oficial:
https://www.w3.org/

Conclusão

Frontend é a área responsável pela interface visual das aplicações web. Para seu desenvolvimento são utilizadas tecnologias como HTML, CSS e JavaScript. O funcionamento da web depende do modelo Cliente-Servidor, enquanto o W3C garante a padronização das tecnologias utilizadas na internet.
