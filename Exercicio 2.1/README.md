# Table-Based Layout

## Por que essa técnica é antiga?

O uso de tabelas para criar o layout de páginas era comum antes da evolução do CSS. Atualmente essa prática não é recomendada porque mistura dados com apresentação, dificulta a manutenção, reduz a acessibilidade e torna a responsividade mais complicada.

## Dificuldades encontradas

- Código maior e menos organizado.
- Alterações no layout exigem modificar a tabela.
- Adaptação para celulares é mais difícil.

## Comparação com HTML semântico

O HTML semântico utiliza elementos como `header`, `nav`, `main`, `section` e `footer`, deixando o código mais organizado, acessível, fácil de manter e compatível com técnicas modernas de responsividade.
