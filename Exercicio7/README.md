Sistema de Cadastro de Produtos - Exercicio 7
Objetivo

Criar um sistema web para uma loja fictícia de tecnologia, permitindo visualizar produtos cadastrados utilizando JavaScript.
Parte 2 - Listagem Dinâmica

Nesta etapa foi criada uma listagem automática de produtos.

Os produtos são armazenados em um array JavaScript e exibidos na página através de loops.
Tecnologias utilizadas

    HTML5
    CSS3
    Bootstrap 5
    JavaScript

Funcionalidades

    Página inicial
    Cadastro de produtos
    Listagem dinâmica
    Navegação entre páginas

Melhorias realizadas

    Criação de array com produtos fictícios.
    Uso de loop para gerar cards automaticamente.
    Layout responsivo usando Bootstrap.
    Cards adaptáveis para celular, tablet e computador.
